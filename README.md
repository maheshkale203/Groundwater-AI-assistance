I’m excited to share my latest project: The Groundwater AI Assistant! 🌊🤖

Accessing and understanding government groundwater data (like the INDIA-Groundwater Resource Estimation System) is usually restricted to scientists or data analysts who can navigate massive spreadsheets. I wanted to change that and make this critical environmental data accessible to everyone—from local farmers to policymakers—in their native language.

I built an autonomous, agentic AI pipeline that completely automates data wrangling and analysis using a conversational interface.

✨ Key Features:
🔹 Smart Intent Parsing: Uses Groq's Llama 3 models to instantly route queries (General Chat vs. Single Year Data vs. Historical Trends).
🔹 Automated ETL: Dynamically detects geographical columns and melts wide-format monsoon data into clean, queryable formats using Pandas.
🔹 Multilingual Accessibility: Users can ask questions in Hindi, Marathi, Bengali, or English, and the LLM natively analyzes the data and responds in their mother tongue—no clunky translation plugins needed!
🔹 Dual-Layer Visualizations: Generates interactive Altair charts with a "Simple View" (district averages) for quick insights and an "Advanced View" (box plots) for statistical well variance.

This project was an incredible dive into agentic AI systems, LLM orchestration, and data-centric Python development.
